    How it works
    
    
    
      
    
        
    Drop
    
        
    Your text or file is saved on this server and you get a link and a QR code. Anyone with the link can open it until it's deleted, after 2, 4 or 7 days.
    
        
    Add a password and they'll need that too. It's stored only as a bcrypt hash. Files can be up to 30 MB.
    
      
    
      
    
        
    Beam
    
        
    Both devices open PeerDrop and join the same room. Text and files then go straight between the two browsers, encrypted, with no size limit.
    
        
    The server only introduces the devices. If they can't reach each other directly, the data passes through a relay on this server, still encrypted and never saved.
